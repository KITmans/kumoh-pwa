[1. 공지사항 목록 (List)]

학사안내 주소:

2. 파싱할 HTML 핵심 구조:
- 리스트 아이템: <li> 태그나 <tr> 태그 단위로 반복돼.
- 제목과 링크: <a href="?mode=view&articleNo=번호..."> 태그를 찾아줘. 이 안의 텍스트가 '글 제목'이고, href 속성에서 'articleNo(글 번호)'를 반드시 추출해서 저장해 둬야 해. (이 번호가 나중에 본문 상세 페이지로 넘어갈 때 쓰이는 키 값이야)
- 메타 정보 (부서, 날짜, 조회수): <span class="mobile-info"> 태그 안에 <span> 으로 쪼개져서 들어있어.

이 HTML 구조를 바탕으로 학사안내 목록을 예쁘게 보여주는 UI 코드를 짜고, 사용자가 목록을 클릭하면 추출해둔 'articleNo'를 이용해 아까 만든 2단계(본문 상세) 화면으로 넘어가게 연결해 줘.

요구사항: 여기서 글 제목, 날짜, 작성자, 그리고 '본문으로 넘어갈 글 번호(고유 링크)'를 파싱해 줘.


[2. 공지사항 본문 (Detail)]
본문 주소 규칙: 선택한 카테고리의 기본 주소(예: sub06_01_01_01.do 등)?mode=view&articleNo=[글번호변수]&article.offset=0&articleLimit=10
(앞의 카테고리 주소와 뒤의 글 번호를 둘 다 상황에 맞게 변수로 처리해 줘)
파싱할 HTML 핵심 구조:
- 첨부파일: <dl class="attached-file-wrapper"> 안의 <a class="file-down-btn" href="..."> (다운로드 링크와 파일명 추출)
- 본문 내용: <div class="board-contents"> 안의 모든 내용 (텍스트 및 내부 서식/이미지 유지하여 렌더링)
이 두 클래스(attached-file-wrapper, board-contents)를 타겟으로 크롤링해서 상세 화면 UI를 만들어줘.
요구사항: 목록에서 제목을 누르면 이 주소로 요청을 보내서 새 화면(상세 페이지)을 띄워줘. HTML에서 텍스트 본문 내용을 깔끔하게 보여주고, 첨부파일(<a href="...">)이 있다면 다운로드할 수 있는 버튼도 만들어줘.
